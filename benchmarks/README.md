# Render benchmarks

## These only apply to macOS and linux systems, NOT Windows!!! On windows, simply run `python ...` outside of wsl.

Run `conda run --no-capture-output -n manimgl python benchmarks/run.py --baseline` from the repository root to create or replace `benchmarks/results/baseline`. The 49 scenes each render twice at 854×480 and 15 fps: first with a fresh disk cache, then with that cache reused in a new process. These timed exports use Manim’s default encoder. Every frame sent to the encoder is also streamed to a raw capture in an OS temporary directory during those same runs. After all timings finish, the captures are compressed losslessly, their raw files are deleted, and every frame is checked. No scenes are re-rendered for validation. A successful baseline keeps one lossless reference per scene and automatically compiles a player-compatible `suite.mp4` for review. Timings include default movie encoding and raw capture writes (also recorded as `capture_write_seconds`); lossless compression, validation and preview compilation are excluded; OS/driver caches are not reset.

Run `conda run --no-capture-output -n manimgl python benchmarks/run.py` after a change to validate the captured frames from both timed phases against the same saved reference and print timing changes automatically. Use `--only SceneName AnotherScene` to check selected scenes. Validation checks frame counts, dimensions, playback timing and bounded pixel differences, with tolerances calibrated from baseline repeatability. Failed checks exit nonzero and keep logs, movies and visual diffs; successful comparisons discard their movies. Changed scene sources or render configuration require a new baseline.

Each run saves one compact `results.json` with timings, resource measurements and visual status; there are no duplicate CSV or validation reports. The console shows first/cached timings, average CPU/GPU/memory, and comparison percentages (negative means faster). GPU usage is device-wide and may be unavailable. Results are disposable: delete `benchmarks/results` whenever you like and rerun `--baseline`. Scene files live in `scenes/`; support code and regression tests live in `support/` and `tests/`.

The `default-export-captured-frames-v1` protocol requires a new baseline; timings from the former separate-render protocol are incompatible. Capture and comparison stream frames with bounded memory. Failed captures are retained for diagnosis; successful comparisons discard their movies.
